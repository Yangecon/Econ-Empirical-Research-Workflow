# Attribution and licensing

[English](LICENSING.md) · [中文](LICENSING.zh-CN.md)

No project-wide open-source license has been selected for the newly assembled library. This packaging step does not assign a license to the user's code or grant rights over source-paper images. Third-party components retain their own notices and licenses.

- Source-paper images (gallery only) are attributed per item and in SOURCES.md. Their inclusion records an attributed visual reference and does not establish redistribution permission.
- The bundled Borusyak event_plot sources retain LICENSE_BORUSYAK; the local patch is described in event_plot_patch.md. coefplot retains its upstream LICENSE. Other Stata packages retain author headers and source/version/hash records in stata_packages.json; no blanket license is inferred for them.
- Cameroon administrative boundaries retain the provider attribution and dataset license in the geographic_choropleth template's ATTRIBUTION.md, api_metadata.json and retrieval.json. Example region values are synthetic.
- Synthetic examples, code and documentation must not be cited as reproductions of the papers' numerical results.
