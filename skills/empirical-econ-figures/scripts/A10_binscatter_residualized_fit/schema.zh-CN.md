# 观测 CSV 约定

[English](schema.md) · [中文](schema.zh-CN.md)

UTF-8 CSV，表头 `id,rx,ry` 可按任意顺序排列：

| 列 | 含义 |
| --- | --- |
| `id` | 非空、唯一文本标识符。以字典序打破 `rx` 并列。 |
| `rx` | 有限、已残差化的横轴变量。 |
| `ry` | 有限、已残差化的纵轴变量。 |

两种实现均在以下两步使用输入 CSV 中的**每条完整行**：

1. 在观测层面拟合含截距的不加权 OLS：`ry = intercept + slope × rx + error`。
2. 按数值 `rx`、再按文本 `id` 排序。排序后从 1 开始的秩为 `r`，样本量为 `N`，指定箱数为 `B`，分配 `bin = floor((r−1) × B / N) + 1`。计算各箱 `rx` 与 `ry` 的算术均值并绘制。

当 `2 ≤ B ≤ N` 时，该规则恰好生成 `B` 个非空箱，箱大小最多相差一条。并列 `rx` 可按明确的 `id` 规则跨越箱边界。线在**原始观测**上拟合，绝不在图中的箱均值上拟合。`rx` 必须有变异。实现不残差化原始变量，也不推导 IV 估计。若复现第一阶段设定，应先在上游用同一共同分析样本和控制变量准备两个残差，再单独记录过程。
