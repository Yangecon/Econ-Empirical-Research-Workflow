# 原始观测输入约定

[English](schema.md) · [中文](schema.zh-CN.md)

UTF-8 CSV 每行一个观测值。必需列：`id`（唯一非空行键）、`group`（稳定 ID）、`group_order`（从 1 开始连续正整数）、`group_label_en`、`group_label_zh` 和有限数值 `value`。每组恰有一个顺序和每语言一个标签。来源模型概率要求 `[0,1]` 内取值；示例和默认轴强制该边界。其他指标须用 Python `--ymin`/`--ymax` 或 Stata 最后两个参数覆盖全部值，并修改两脚本顶部轴标签。列顺序无关。

两实现使用 Hyndman–Fan type 7 计算四分位数：排序值 `x_(1)...x_(n)`，位置 `h = 1 + (n-1)p`，对 `p = .25, .5, .75` 在 `floor(h)` 与 `ceil(h)` 之间线性插值。并列值仍作为独立观测。下上围栏为 Q1−1.5×IQR 与 Q3+1.5×IQR。箱须止于含边界围栏内最小和最大真实观测，围栏外值绘为离群点。这是明确选定的可复现绘图规则，不声称是来源论文的软件默认值。两脚本分别导出组汇总 CSV 供比较。

箱线图描述给定值，不估计模型、构造敏锐度十分位或提供抽样不确定性。若绘制估计值，上游须计算这些值及分组。
