# 双边流输入与核算

[English](schema.md) · [中文](schema.zh-CN.md)

同时传入 **`--flows` 与 `--nodes`**，或均不传入以使用模拟示例。`flows.csv` 包含 `source`、`destination`、`amount_usd_billion`；每个有序来源—目的地组合至多出现一次。金额以**十亿美元**为单位，须有限且非负。零边是有效输入，不绘制带。每条正值流带在来源和目的地使用相同纵向尺度：一个图形单位表示十亿美元。颜色编码目的地，节点顺序来自 `nodes.csv`；排序只影响位置，不改变厚度。

`nodes.csv` 包含 `side`（`source` 或 `destination`）、`node`、可选且完整的 `label_zh` 与 `total_usd_billion`。行顺序分别定义左右两侧自上而下的排列。所有边端点均须声明。节点总额可为零；仍显示标签，但无正高度方框。**每个**节点的相连边金额之和必须在数值舍入容差内等于声明总额。全部来源总额之和必须等于全部目的地总额之和。未匹配余额触发错误，而非从图中消失。若要展示真实未匹配类别，须以如实标签显式提供来源或目的地节点及边。

图形是从避税地关联公司所在地到最终公司国家的描述性重新归属图。路径编码用户已提供的金额；脚本不推断所有权、不构造企业链接、不估计重新分配。示例流量与节点值为虚构，不应理解为原始2017年金额。
