# A05 · `rdplot` package variant

[English](README.md) · [中文](README.zh-CN.md)

This is a Stata `rdplot` alternative to the accepted manual two-panel synthetic RD figure. It reads the same explicit input CSV, uses cutoff 0, a first-order fit with uniform kernel, fixed left/right bandwidths 16 and 25 for Outcomes A and B, and ten evenly spaced bins per side. The windows and bin counts are illustrative choices, not data-selected bandwidths or inferential RD estimates. The syntax follows the [authors' Stata example](https://github.com/rdpackages/rdrobust/blob/main/stata/rdplot_illustration.do). The executed `rdplot` version is 11.1.0 (22 May 2026); see package_manifest.json (`package_manifest.json`) for its source hash. The command came from pre-existing Stata PLUS; no global installation occurred in this task. For a portable environment, install the official `rdrobust` suite into a project-local ado directory and pass that directory to the runner.

The runner generates English figures only: `rdplot_en.png` has panel headings but no overall title or bottom notes; `rdplot_en_title.png` demonstrates the title option. Earlier validation also tested Chinese output, which is no longer generated by the demo runner or included in the gallery. The code is plot_rdplot.do (`plot_rdplot.do`); run_demo.do (`run_demo.do`) accepts a template root, an **explicit input CSV path**, an output directory, and an optional local ado directory. The plotting file itself accepts `input.csv output.png en|zh 0|1`.

The package exports one bin table per panel (`*_rdplot_bins.csv`) and a four-row side-fit table (`*_rdplot_fits.csv`). On this synthetic demo, 40 package bins matched the manual Stata bin counts and sample-mean x/y values; maximum mean difference was `2.14e-14`. All four side-fit intercepts, slopes, and ranges matched to `3.11e-15`. `rdplot` displays the **bin midpoint**, while the manual figure displays the **sample mean of running values** in each bin; their largest x-coordinate difference here was `0.104`. The plotted points therefore differ horizontally even though bin membership and means agree. Both figures are descriptive and do not supply RD confidence intervals or causal inference. Validation (`validation.json`) records the numerical comparison, and schema.md (`schema.md`) explains the generated columns.

The four final Stata logs and validation log (`validation.log`) carry completion markers. The English and Chinese defaults and titled examples were visually inspected. These results use synthetic observations rather than the source paper's data.


Example images and execution evidence are archived in the gallery; the installed skill contains code and inputs only. Supply the parent template demo.csv explicitly to run_demo.do.

Canonical figure name: `rd_binned_outcomes`
