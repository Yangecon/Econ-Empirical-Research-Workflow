# 输入 CSV 约定

[English](schema.md) · [中文](schema.zh-CN.md)

每行对应一个 `variant`–`panel`–`term`–`group` 估计。列顺序无关；两种实现均按表头导入。

| 列 | 是否必需 | 含义 |
| --- | --- | --- |
| `variant` | 是 | 选择配置的图，例如 `robustness` 或 `subgroup`。 |
| `panel` | 是 | 绘图脚本中配置的面板 ID。 |
| `panel_order` | 是 | 连续的 1–4 显示顺序，面板内部一致。 |
| `term` | 是 | 设定或结果的类别 ID。 |
| `term_order` | 是 | 从 1 开始的连续顺序；绝不由字母排序推断。 |
| `term_label_en`, `term_label_zh` | 是 | 各语言的轴类别标签。 |
| `group` | 是 | 绘图脚本中配置的组 ID。 |
| `group_order` | 是 | 与配置匹配的组顺序。 |
| `estimate` | 是 | 点估计。 |
| `ci_low`, `ci_high` | 通常需要 | 与估计单位相同的区间端点，必须包含估计值。 |
| `se` | 回退 | **两个**区间端点均为空时，两种实现计算 `estimate ± 1.96 × se`。乘数可配置（Python 用 `--ci-multiplier`；Stata 修改标明的计算）。这是针对给定标准误的正态临界值近似，不能替代论文自己的区间规则。 |

每个配置组必须在各面板的每个有序条目上恰有一行。横向多面板图必须共享相同有序条目以对齐行。各面板的效应轴范围由自己的区间和零独立确定。面板标题及效应轴单位标签在各脚本配置块中分别设置。可视化读取估计和区间，不计算估计量、聚类标准误或样本量。
