# 月度阶段输入

[English](schema.md) · [中文](schema.zh-CN.md)

UTF-8 CSV，每个队列一行。列顺序任意。

| 列 | 含义 |
| --- | --- |
| `cohort` | 唯一非空队列ID。 |
| `cohort_order` | 显示顺序，从1开始的连续整数。 |
| `cohort_label_en`, `cohort_label_zh` | 双语行标签。 |
| `n` | 显示在队列旁的正整数计数；在配套来源说明中定义其人群。 |
| `status` | `policy` 或 `nonpolicy`；至多一行 `nonpolicy` 汇总。 |
| `transition_start`, `transition_end` | 政策行必需区间，日期为 `YYYY-MM-01`。 |
| `enforcement_start`, `enforcement_end` | 政策行可选成对区间端点，日期格式同上。 |
| `termination_month` | 可选的共同月初终止标记；所有非空值须相同。 |

区间为**半开**：包括起始月份，不包括结束月份。因此过渡期 `[2020-04-01, 2020-08-01)` 覆盖4–7月，执行期可在8月开始而无重叠。政策行要求非空过渡区间；执行端点须同时提供或同时为空，且执行期开始不早于过渡期结束。若提供终止月份，任何阶段不得延伸至其后。非政策行不得有阶段区间。脚本拒绝倒置或重叠区间，以及非月初日期。显示日历由解析后的月度日期计算。图形不作因果主张，也不说明阶段内遵从情况。
