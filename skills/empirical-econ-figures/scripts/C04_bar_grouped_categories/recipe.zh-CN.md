# C04 · 分类比例的双组并列条形图

[English](recipe.md) · [中文](recipe.zh-CN.md)

`grouped_category_bars` · C04

按预设类别顺序比较两组比例，使用各单元格的分子和分母、零基线及黑白填充。

分类依据：基础分组条形图代表：明确类别顺序、组别、比例分母和零基线，长标签用横向并列条形；原图是按中奖金额与时点分组的入学率描述，不由柱高差异直接推断因果。

标签：组间比较, 类别份额, 柱状图

## 来源与范围

[Parental Resources and College Attendance: Evidence from Lottery Wins (2021)](<https://doi.org/10.1257/aer.20171272>); Figure 1; PDF p.13

原始页图与 PDF 图注已核对；仅以模拟数据演示画法

## 运行

仅生成英文图，不再同时绘制中文版；说明文档保留中英文。

在本模板目录中运行：

```shell
python plot.py --input demo.csv --output YOUR_PROJECT/figures/grouped_bars.png --lang en
```

`--lang zh` 切换中文；`--title` 开启标题，默认没有。当前模板明确支持两组；组别ID、标签、类别及其顺序在脚本顶部配置。比例横轴从零开始，空心/实心条仅区分组别，不表示统计显著性。

每个类别×组别必须恰有一行，整数计数满足 `0 <= numerator <= denominator` 且分母为正。分母是该格合格观测数，不是全样本人数；输出 `_rates.csv` 同时保存原始计数和计算比例。类别按配置排列，不按柱高或字母排序。

原图描述按中奖金额和发生时点分组的一年内入学比例，没有显示单元格计数或区间。本模板的分子、分母和类别标签是模拟示例，并未还原论文数值；不计算调整效应、置信区间或因果检验。

将 YOUR_PROJECT 替换为研究项目路径；含空格的路径加引号。默认输出无整体标题和底部注释。

## 验证

12个模拟单元格、6个类别、2组。中英文及标题开启模式均实际执行、视检；标题图例重叠已修正。比例精确等于各格分子/分母；分子超分母、零分母、重复格、非整数计数及第三组配置均按预期拒绝。
