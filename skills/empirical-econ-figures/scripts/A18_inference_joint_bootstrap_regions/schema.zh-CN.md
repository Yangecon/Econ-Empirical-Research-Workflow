# 外部构造的联合区域输入

[English](schema.md) · [中文](schema.zh-CN.md)

网格 CSV 列：`x_center,y_center,x_lo,x_hi,y_lo,y_hi,in90,in95,in99`。每个笛卡尔网格位置一格。边界必须构成完整规则矩形网格，格宽与格高分别相等且为正，中心唯一。归属标记为 0/1，每格必须满足 `in90 <= in95 <= in99`。全部标记为零表示位于显示的联合区域之外。标记由上游联合推断提供，这里**不**从边际区间或参数形状计算。

点 CSV：恰好一行，列为 `x,y`，值有限。轴变量沿用来源：x = EP(-10%) - EP(-30%)；y = EP(-30%)。黑色参考线是绘图区内的集合 `x+y=0.5`。核验输出含 `region`，取 90、95、99 或 0，供互斥区域着色。若任一 99% 格点位于网格外边缘，Python 命令警告并记录 `region_hits_boundary=true`；应扩展输入网格或披露截断。示例网格不接触边界。
