# A01 · 事件研究、前后均值与静态 DID

[English](README.md) · [中文](README.zh-CN.md)

本示例使用 70 个个体、14 期的平衡面板，共 **980 行**。35 个个体从事件时间 0 起接受处理，35 个为始终未处理的对照组。时间为 −6 至 7，基准期为 −1。数据为模拟数据，Python 与 Stata 各自进行实际回归，不把预先指定的系数当作估计结果，也不复现参考论文的原始数值。

## 两条均值线

保持基准期系数 β₋₁ = 0：

- Pre mean = (β₋₆ + β₋₅ + β₋₄ + β₋₃ + β₋₂ + 0) / 6。
- Post mean = (β₀ + … + β₇) / 8。
- DID 对比 = Post mean − Pre mean。

基准期仍用空心圆点，没有单独的置信区间或显著性检验。但该期属于处理前样本，所以必须计入前期均值的分母。本例不把前期均值重新归一化为零；后期横线的高度本身不是 DID 或 ATT。前期均值也不能代替联合平行趋势检验。

该等式在本例的同期处理、平衡面板、相同样本与时间窗口、无额外控制变量或回归权重的设定下成立。不能据此假定交错处理、非平衡面板或其他估计器也满足相同等式。导入外部结果时，输出首先是指定权重下的系数对比，是否有 DID/ATT 含义由研究设计决定。

## 回归与协方差

静态模型为 `y = 个体固定效应 + 时间固定效应 + τ × treated × post + 误差`。事件研究使用相同的个体与时间固定效应，加入除 −1 以外各期的 `treated × 该期指示变量`。

Python 使用双向去均值后的 OLS，Stata 使用原生命令 `regress`。两者按个体聚类，验证时统一采用不带小样本修正的 CR0 协方差和正态 95% 区间。Stata 的默认聚类协方差带有限样本修正；程序明确撤销该修正后再比较。不同参数数目的模型若直接保留默认修正，其报告的标准误可能不同。

对均值权重 w，方差为 `w' V w`。对后减前，令 `c = w_post − w_pre`，其方差为 `c' V c`，必须使用完整协方差。不能把两条均值的方差直接相加，也不能只用各期标准误计算。

每条水平阴影带是对应**标量均值**的置信区间，不是整个动态路径的同时置信带。逐期区间决定估计点的实心或空心状态；归一化基准点始终空心。

## 输入与输出

`demo_panel.csv` 的字段为 `unit,event_time,treated,post,y`。`estimate_demo_panel.py` 记录固定种子的数据生成与 Python 估计方法；同名绘图 `.py` 默认读取随包面板并重新估计。Stata 的 `MODE "demo"` 从同一份面板独立估计。

外部估计输入为 `term,event_time,estimate,is_reference,weight`，其中 `weight` 可省略、默认 1。基准期的系数及协方差对应行列必须为零；协方差 CSV 用相同 term 标记行列，并提供所有非对角元素。处理前均值包含基准期；权重在各窗口内归一化。

`demo_contrasts.csv` 保存前均值、后均值、后减前、静态 DID，以及按个体前后变化直接计算的独立核对结果。绘图输出中的 `_summaries.csv` 保存两条均值线，`_contrast.csv` 保存后减前及其标准误与区间，`_periods.csv` 保存逐期结果。具体命令与输出路径设置见同目录的 [使用说明](recipe.zh-CN.md)。

默认生成英文图，无总标题或底部注释；标题可显式开启。−1 使用空心圆点。`--post-is-att` / `POST_IS_ATT=1` 已弃用并报错，防止错误标注后期横线。

## 本例核验数值

| 量 | 估计值 | CR0 标准误 |
|---|---:|---:|
| Pre mean（含 −1） | −0.050198027 | 0.067777896 |
| Post mean | 0.088908434 | 0.076495584 |
| Post − Pre / 静态 DID | 0.139106461 | 0.033701696 |

DID 的正态 95% 区间为 [0.073052351, 0.205160571]。独立核对先计算每个个体的后期均值减前期均值，再计算两组变化之差；同时用组内个体变化离差计算 CR0 方差。具体执行状态、误差和证据见使用说明中的验证部分。
