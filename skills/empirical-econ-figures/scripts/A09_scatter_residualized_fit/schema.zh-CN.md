# 输入结构

[English](schema.md) · [中文](schema.zh-CN.md)

UTF-8 CSV，每行一条观测。必需表头：`panel,group,rx,ry`。

| 列 | 类型 | 含义 |
| --- | --- | --- |
| `panel` | 字符串 | 与两个配置面板之一匹配的 ID；示例 ID `all_fields` 和 `computer_science` 显示为样本 A 和样本 B |
| `group` | 字符串 | 与该面板配置组别匹配的 ID；沿用的示例 ID `medicine`/`other` 和 `ai_late`/`ai_early`/`other` 显示为组 A/其他组以及组 A/组 B/其他组 |
| `rx` | 有限数值 | 输入的已残差化 X，位于横轴 |
| `ry` | 有限数值 | 输入的已残差化 Y，位于纵轴 |

每个列出的面板/组组合至少有一条观测。每个面板至少有三条观测，且 `rx` 有变异。虚线是在该面板全部绘制观测（包括灰色背景组）上将 `ry` 对常数和 `rx` 做 OLS 的拟合线。突出组别不会改变回归权重。模板**不**对原始变量残差化，也不推断固定效应设定。若上游准备残差，应在相同选定行与控制变量上残差化两个变量，在此 CSV 中准确保留共同样本，并单独记录控制变量、缺失处理规则及权重。
