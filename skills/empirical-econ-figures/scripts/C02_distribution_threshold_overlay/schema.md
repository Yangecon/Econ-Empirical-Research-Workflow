# Weighted-distribution input

[English](schema.md) · [中文](schema.zh-CN.md)

UTF-8 raw-observation CSV with `id` (unique nonblank), `series` (configured group ID), nonnegative finite `value`, and nonnegative finite `weight`; each series must have positive total weight. The scripts draw **fixed-width binned percentage mass**, not a fitted kernel density: for series `s` and bin `[a,b)`, bar/line height is `100 × sum(weight in bin) / sum(weight in all observations of s)`. The y-axis says “weighted share per bin (%)”; changing bin width changes height. The visible x domain begins at zero. Every visible bin is half-open, including the last one: values exactly at `xmax` and above remain in the denominator but are omitted from the visible curve. The displayed bins are not renormalized to 100%. Weights are user supplied; the template does not claim they are survey weights.

Threshold IDs, values, labels, line colors, and the one shaded threshold for each series are editable near the top of `plot.py`. Every threshold must be a bin edge inside the plot domain. The result CSV reports `share_below = sum(weight where value < threshold) / sum(all series weights)` for **every series × threshold**. Strict `<` puts exact-threshold values on the upper side. Since `xmin=0`, values are nonnegative, and thresholds align with bin edges, displayed bins fully below a threshold have the same mass as the exact weighted share, including when the threshold equals `xmax`. Shading covers the full edges of those bins. The fill is a visual aid; the CSV is the numerical record. This code does not inflation-adjust, equivalize, derive poverty lines, or estimate sampling uncertainty.
