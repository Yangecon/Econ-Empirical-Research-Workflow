# 加权分布输入

[English](schema.md) · [中文](schema.zh-CN.md)

UTF-8 原始观测 CSV，包含 `id`（唯一且非空）、`series`（已配置的组别ID）、非负有限 `value` 和非负有限 `weight`；每个序列的权重总和须为正。脚本绘制**固定箱宽的百分比质量**，不拟合核密度：对于序列 `s` 与分箱 `[a,b)`，柱/曲线高度为 `100 × sum(weight in bin) / sum(weight in all observations of s)`。纵轴表示“每箱加权份额（%）”；改变箱宽会改变高度。可见横轴从零开始。所有可见分箱均为半开区间，包括最后一箱：恰好等于或大于 `xmax` 的观测保留在分母中，但不出现在可见曲线上。显示的各箱不重新归一至100%。权重由用户提供；模板不声称它们是调查设计权重。

可在 `plot.py` 顶部附近编辑阈值ID、数值、标签、线条颜色，以及每个序列用于填色的一个阈值。每个阈值须位于绘图区内的分箱边界。结果 CSV 为**每个序列 × 阈值**报告 `share_below = sum(weight where value < threshold) / sum(all series weights)`。严格小于号 `<` 将阈值并列值放在上侧。由于 `xmin=0`、数值非负且阈值与箱边界对齐，完全位于阈值下方的可见分箱质量等于精确加权份额；阈值等于 `xmax` 时也成立。阴影覆盖这些分箱的完整边界。填色仅辅助视觉，CSV 是数值记录。代码不进行通胀调整、等价规模换算、贫困线推导或抽样不确定性估计。
