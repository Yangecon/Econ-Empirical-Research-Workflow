# 输入约定

[English](schema.md) · [中文](schema.zh-CN.md)

UTF-8 CSV，列为 `panel,sr,sd,value`，每行是二维五分位网格中的一格。配置面板 ID 为 `te`（企业就业增长效应，对数变化单位）与 `jobs`（每 100,000 欧元补贴带来的新增岗位数）。`sr` 是客观规则五分位，`sd` 是政治裁量五分位，均为 1–5 整数。**每面板必须包含全部 25 个坐标。** 每面板至少有一个已观测估计；拒绝重复或遗漏格点、未知面板、越界五分位、非空非数值以及超出面板配置色阶范围的值。空白 `value` 表示**缺失**，显示为灰色而非零。数值零是已观测值，只有面板声明范围包含零时才合法。

当前色阶可在两脚本中修改：`te: [0.05,0.20]` 对数变化，`jobs: [0,1.25]` 每 100,000 欧元新增岗位。两者使用相同十种 RGB 颜色，但在**每个面板内部**等距划定色阶。第 `k` 档含下端点、不含上端点，最末档同时包含配置最大值。Python 显示十级色条；Stata 显示相同十级图例，边界保留三位小数。两者独立映射已保存点估计，均不计算处理效应、成本效果、不确定区间或显著性。来源 Panel A 是六年就业对数变化，其 90% bootstrap 区间在另表中，没有编码在热图里。
