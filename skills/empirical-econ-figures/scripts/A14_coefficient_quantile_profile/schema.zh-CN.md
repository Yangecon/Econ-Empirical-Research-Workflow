# 输入约定

[English](schema.md) · [中文](schema.zh-CN.md)

UTF-8 CSV，每个数值结果分位恰好一行，按 `quantile_percent` 严格递增排序。必需有限数值列：

| 列 | 含义 |
|---|---|
| `quantile_percent` | **结果分布**的百分位，严格位于 0 和 100 之间，例如 10、20、…、90。 |
| `estimate` | 该无条件分位上预先计算的系数。 |
| `ci_low` | 预先计算的置信区间下端点。 |
| `ci_high` | 预先计算的置信区间上端点。 |

输入至少包含三个唯一分位，且 `ci_low <= estimate <= ci_high`。CSV 列可任意排序。两语言保留系数单位，**不**计算 UQR、聚类标准误或区间覆盖率。来源图报告 ZIP 聚类的 99% 区间；其他用户的区间水平应在 CSV 外说明，不能从端点推断。模拟示例包含九个分位和示意区间，不是来源数值。
