# 给定后验汇总输入

[English](schema.md) · [中文](schema.zh-CN.md)

UTF-8 CSV，每个 `response × shock × horizon` 一行。必需列：`response`、`shock`、以**月**计的非负整数 `horizon`、`median`、`lo68`、`hi68`、`lo90`、`hi90`。所有单元必须在相同期限网格上恰好出现一次，至少三个期限且从零开始。当前演示配置为五行响应、五列冲击；其他研究须在两脚本中修改 ID、双语标签、单位及**响应特定的纵轴范围**。同一行不同冲击共享纵轴，但不同行可用不同物理单位和范围。

每行必须满足 `lo90 <= lo68 <= median <= hi68 <= hi90`；全部数值有限，90% 边界须落在配置响应行范围内。脚本用浅蓝绘制**给定的 90% 后验不确定区域**、深蓝绘制**给定的 68% 后验区域**、黑色绘制中位数路径。不估计 VAR、计算后验或从原始抽取计算区间。

可选的小期限标记使是否排除零可见：实心表示**给定外层 90% 后验区域排除零**（`lo90>0` 或 `hi90<0`），否则为空心。这是显示分类，不是频率派检验、p 值或经济效应证明。标记期限可配置；输入估计与带状区间仍跨所有给定期限连续绘制。输出 `_checked.csv` 为每行记录派生标记 `outer_excludes_zero`。
