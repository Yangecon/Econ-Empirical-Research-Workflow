# D02 · 选择、随机分配与后续选择的时序树

[English](recipe.md) · [中文](recipe.zh-CN.md)

`randomization_decision_tree` · D02

用不同节点区分行为选择与随机分配，沿时间展示实验中的五条观测路径。

分类依据：实验设计决策树：区分随机分配节点、受试者选择及后续结果时点；不能将自选择边标为随机化。

标签：随机对照试验, 随机分配, 序贯选择

## 运行

仅生成英文图，不再同时绘制中文版；说明文档保留中英文。

在模板目录运行：

```shell
python plot.py --spec figures/demo_design.json --output YOUR_PROJECT/figures/design_tree
```

生成英文 PNG/PDF及模拟路径概率表。`--title-en "Title"` 开启英文总标题，默认无总标题和底部notes；阶段名称属于图中结构标签。

初始接受/拒绝是买方选择，之后合同要求保留/取消才是独立随机分配；初始选择不能标为随机处理。原文因样本中一些分支的买方未改变初始选择，省略了这些分支的后续选择节点，并不意味着实验在逻辑上禁止改变选择。

这是固定五叶结构的时序树模板。可输入JSON调整示例概率；若改变实验结构、节点名称或阶段，必须修改绘图函数及路径核对，而非只改概率。仅“初始拒绝且取消合同要求”分支显示进一步接受/拒绝选择，其条件分母是P(A=0,F=0)。E、C、R沿用原图的最终行为代码。路径联合概率以虚构参数计算，只用于说明分母，不显示在图中；来源Figure 1没有给出这些概率。图形不估计处理效应。

将 YOUR_PROJECT 替换为研究项目路径；含空格的路径加引号。默认输出无整体标题和底部注释。

## 验证

中英文默认和标题版实际执行并视检。五条路径的模拟概率之和为1，独立分配约束与条件分母核对通过。主验收修复线条穿过英文分支标签，并明确省略决策节点来自样本行为而非设计逻辑限制。
