# 两张对齐的输入表

[English](schema.md) · [中文](schema.zh-CN.md)

`effect_demo.csv` 示范**上方图**的数据表。必需 UTF-8 列：`panel`（ID）、`panel_order`（配置整数顺序）、`x`（有限数值点位置）、`estimate`、`ci_low`、`ci_high`。每个效应点一行；`panel` + `x` 唯一，且 `ci_low <= estimate <= ci_high`。边界必须落在两脚本的面板特定配置范围内。这些是给定区间端点。模板不估计模型、Wilson 区间、聚类稳健标准误或显著性。

`support_demo.csv` 示范**下方直方图**数据表。必需列：`panel`、`panel_order`、`x_left`、`x_right`、`count`。每箱为 `[x_left,x_right)`（最后一箱可在上游包含右端点），须有 `x_left < x_right`、箱不重叠、面板内箱宽相同，以及非负整数的无条件观测数。两程序直接绘制输入计数，不从上方估计推断计数，也不声称每个计数就是估计样本量。面板 ID/顺序必须匹配配置的效应面板。列顺序无关。

每个面板上下两轴共享**相同的 x 变量与范围**，但纵轴独立：上方纵轴是估计或比率，下方纵轴是数量。各面板可有不同效应单位与 x 范围。用于其他研究时修改 `plot.py` 和 `plot.do` 的 `CONFIG` 块。区间置信水平、估计量及支持分布分母定义须由上游分析说明。来源图中 (a,c) 为平均迁移率及 Wilson 得分 95% 区间，(b,d) 为控制固定效应后的模型系数及双向聚类 95% 区间；代码不会自动保留任一估计程序。
