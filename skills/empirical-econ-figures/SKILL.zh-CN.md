本库包含 50 个已验收的来源或方法变体，归为 40 个绘图目标。整理范围是用户提供的 2021–2026 年经济学五大期刊论文（AER、QJE、JPE、Econometrica 和 REStud）及部分 NBER 工作论文，涉及六个日历年份；并非对这些刊物全部已发表论文的穷尽收录。实现和验证限制见[目录](<references/catalog.zh-CN.md>)。最终范围仅含已验收实现；所有候选建议均已决定不予收录，无待定候选。

从 [40 个分组绘图目标](<references/targets.zh-CN.md>)入手，按分析目的和可用输入选择变体，再阅读其链接的操作说明。结果图通常提供 Python 和 Stata 两种版本；HonestDiD 是明确批准的仅 Stata 例外。描述性图形可能仅提供 Python。应使用随附实现，不要根据外观近似猜测其统计推断逻辑。

按所绘数值的来源分类：简约式估计、结构式估计、描述统计、研究设计，或预测与算法评估。异质性、稳健性、福利、校准、反事实和图形几何形态作为标签。反事实不一定来自结构模型；校准概率不一定是估计得到的结构参数。请遵循各目录条目的数值来源说明。旧文件夹名称仅用于存储路径兼容，不代表当前分类。

目录同时记录合并后的绘图目标和已验收的来源特定实现。当几何形态一致时，可复用折线或散点渲染器，但必须保留不同的统计输入，包括风险集、权重、参考期、协方差和区间含义。合并后的目标名称不表示已经存在统一的可执行接口。可执行目录只收录已验收实现。

选择相似图型或迁移到其他研究主题时，参阅[选择指南](<references/selection_guide.zh-CN.md>)。将生成文件写入正在开展研究的项目，已安装技能包内部不存放 PNG 输出。

安装方法、共享依赖及与估计和草稿同步阶段的边界，见[环境与工作流程衔接](<references/setup.zh-CN.md>)。

## 共享约定

- 默认生成图中不放标题、副标题、图注或底部注释。仅在用户要求时开启标题。保留坐标轴标签、单位、图例和有用的面板标签。来源署名与统计说明放在配套 Markdown 或论文草稿中。
- 使用稳定的 snake_case 文件名、白色背景、克制的配色和清晰可读的图例。保存 PNG 以供检查；在支持时保存矢量 PDF 用于论文。
- 事件研究默认以 -1 期为参考期。事件研究及其他动态效应估计中，显示区间不包含零时使用实心点，否则使用空心点。记录区间水平，以及其属于频率学派区间还是后验区间。参考期归一化不是估计效应，也不是显著性检验。
- 上述点型规则适用于置信区间或后验区间，不适用于集合识别边界或情景包络。集合边界模板用点型区分输入路径；边界不含零并不表示统计显著。
- 绘制输入估计器的实际结果。在图像之外记录置信水平、逐点或同时覆盖性质、参考期、权重、样本和聚类设定。图形形态本身不能证明因果识别成立。
- 处理前后均值的不确定性需要完整协方差矩阵：各均值的方差为 w'Vw，后减前的方差为 (w_post-w_pre)'V(w_post-w_pre)。A01 使用同期处理的平衡面板、相同样本与窗口、不加额外控制变量或回归权重；基准期零值计入前期均值的分母，此时后减前等于静态 DID。该归一化下不能直接把后期横线的高度称为 DID 或 ATT；也不能将这一等式推广到交错处理、非平衡面板或不同回归设定。
- 模拟示例用于展示画法，不得将其表述为论文结果复现。在操作说明中保留来源论文、图形署名及数值数据状态。
- 验证输入结构并检查导出图像。明确报告是否实际执行了每种语言；仅完成静态审查不等于 Stata 成功运行。

## 由命令执行推断的图形

交错处理 DID 应先运行模拟数据估计流程，再绘图：六个实际运行的 Stata 估计器（包括 `jwdid`）导出供 Stata 和 Python 共用的结果表。保留各估计器的支持范围和处理前时期含义；不得为对齐曲线而生成缺失系数。

HonestDiD 使用 `honestdid_sensitivity` 操作说明。先对数据运行事件研究估计器，再将按顺序排列的系数和完整协方差矩阵传给 `honestdid`；通过该包分别绘制相对幅度约束和光滑性约束下的敏感性区间。在图外说明目标处理后对比、被省略的基准期和 M 网格。稳健区间的中点不是新的效应估计。光滑性约束 M=0 允许线性差异趋势，并不等同于常规平行趋势区间。程序包运行成功不代表识别假设得到验证。

## 可迁移资源

目录链接至每项可用操作说明及对应代码。本技能包不存放 PNG；视觉预览和来源裁图保留在独立画廊。项目级依赖文件与验证报告说明已测试环境。

工作流程分派可读取 [catalog.json](references/catalog.json)，其中包含已验收模板的标识、分类、语言、入口、输入结构和示例输入。路径相对于技能包根目录。调用前先阅读所选操作说明：各模板采用与用途对应的输入约定，并不假定存在统一命令接口。


默认仅生成英文图，不再额外生成中文版成图。中英文说明页与成图语言分别管理；旧验证记录中的中文图测试属于历史验证。
