# 选择与调整图形

[English](selection_guide.md) · [中文](selection_guide.zh-CN.md)

先根据展示的统计对象选择，再考虑版式。图形标记相似，不表示估计目标相同。

| 输入／目的 | 适用图形系列 | 调整时必须保留 |

| 按事件时间排列的系数 | 事件研究图 | 数值型事件时间、省略的参考期、估计器对应的区间、实心与空心的显著性标记规则 |
| 多组动态系数 | 分组事件研究图 | 组别身份、小幅数值偏移、共同的比较尺度 |
| 动态效应及窗口均值 | 带处理前后均值的事件研究图 | 完整协方差矩阵、固定的归一化权重、时间窗口、独立的标量均值区间 |
| 多个结果变量或模型设定 | 系数图／森林图 | 结果变量单位、模型标签、置信区间含义；尺度不同时采用分面 |
| 原始或残差化的成对观测 | 散点图／分箱散点图 | 点的观测单位、残差化样本、实际拟合和分箱定义 |
| 水平断点附近的结果变量 | 分箱断点回归图 | 左右两侧分别分箱与拟合、阈值处分配规则、带宽、结果变量范围、上游控制变量 |
| 斜率变化附近的结果变量 | 连续折点面板图 | 阈值处相同的拟合水平、左右两侧斜率、运行变量原始单位、各结果变量独立尺度 |
| 观测分布 | 直方图／经验累积分布图／箱线图 | 分母、权重、分箱或分位数规则、共同尺度 |

| 效应估计与对应样本量 | 对齐的效应与直方图面板 | 独立输入表、真正共享的横坐标、两个面板分别标明的纵轴单位 |

| 预测信念与参考概率 | 概率校准图 | 正确的横纵轴角色、45 度基准线、明确的分箱规则、条件离散程度与均值不确定性的区别 |
| 税收跳跃阈值附近的分布 | 带反事实的扎堆分布图 | 观测与反事实序列使用相同单位、固定分箱、跳跃阈值及排除区间边界、由外部估计的扎堆统计量 |
| 两个联合估计的量 | 联合自助法区域图 | 联合覆盖率、已保存的区域构造、参考不等式和点估计；边际区间不能恢复联合区域 |

## 去重

若两幅来源图仅在主题、标签或颜色上不同，保留一个代表即可。若面板结构、不确定性、分组或统计对象改变了所需输入或解读方式，则保留有文档说明的变体。例如，描述性的经验累积分布图与分位数处理效应图是不同图型；将相同的事件研究设计用于另一个结果变量，通常不需要新增模板。

每个选定代表均在已知范围内保留论文、年份、DOI、图号与面板、PDF 页码及本地来源。未知元数据保持未知。补充截图只有经过图像与图注核对后，才可与某篇论文关联。

带历史事件注释的趋势图可复用时间趋势系列，但必须实际实现事件标签层，才能承诺该功能。逐日监测日历采用不同的输入结构。同样，集中曲线不是经验累积分布图，会计分解瀑布图也不是普通分组柱状图。

来源论文中的分析作用决定所需编程语言。模型估计概率的箱线图仍按结果图处理，即使箱线图经常用于描述统计。若后续调整将仅提供 Python 的描述统计模板改为估计效应图，则需要经过检查的 Stata 对应版本，才能声称满足本库结果图的双语言约定。

## 迁移至真实数据

将模板复制到研究项目，或将输出位置指向该项目。用经过验证的数据或已保存的估计结果替换模拟 CSV。重命名列之前先读操作说明：不同模板可能接收预先计算的置信区间、标准误或完整协方差矩阵。不要根据边际标准误虚构协方差，也不要仅为缩窄区间而改变置信水平。

坐标轴标签和单位放在图内。引用、样本构造、估计器、控制变量、聚类、权重和限制放在相邻草稿或图注中；默认关闭图内标题和底部注释。允许保留面板标签与图例。画廊中的模拟数值用于展示画法，不能支持实证结论。

动态效应点型遵循用户约定：显示区间不含零时为实心，否则为空心。若有嵌套区间，需说明由哪个区间水平决定点型。后验可信区域不含零并不自动等于频率学派显著性检验；配套文字必须保留其后验解释。脉冲响应的预测期从冲击发生时开始，不一定具有事件研究所省略的处理前基准期。

## 区间与包络的含义

| 输入对象 | 图形可传达的含义 | 图形不得自行附加的含义 |
|---|---|---|
| 频率学派置信区间 | 已保存的点估计，以及指定方法下的不确定性 | 新的聚类规则或同时覆盖声明 |
| 先验区间 | 指定先验分布的分位数 | 抽样置信或实证显著性解释 |
| 后验区间 | 指定模型、先验及数据下的可信区域 | 根据不含零推断出的频率学派 p 值 |
| 集合识别响应包络 | 每个预测期允许的最小与最大响应 | 推断出的置信水平或显著性检验 |
| 情景包络 | 明确的替代假设或政策参数产生的范围 | 缺乏额外依据的抽样置信水平或识别集解释 |
| 条件四分位距 | 明确定义的箱内个体结果或信念中间一半的范围 | 条件均值的置信区间 |
| 可容许路径的逐点中位数 | 每个预测期各自的中位数 | 整条中位数曲线是一条联合可容许结构路径的断言 |

在操作说明和论文草稿中，将这些定义放在图形附近。图内不放注释，不意味着无需记录这些信息。

带状连接图既可能表示定量流量，也可能表示定性关系。只有当边流量和节点总量均有定义时，才使用定量桑基图模板；来源图中出现宽连接带，本身并不能证明带宽表示频数或金额。同样，将投资存量从注册地重新归属至最终所有者所在地，并不自动等同于某一时期的现金流量。

决策树可能因观测样本中无人改变主意而省略后续选择。这种由样本事实造成的省略，不等同于设计规则禁止该选择。必须区分参与者决策与随机分配；分支比例并不表示每次分叉都是随机的。

图中两条区间带还可能来自**同一置信水平下的不同推断方法**，例如聚类稳健区间和 Conley 区间。不要将它们改标为 68% 与 95% 区间，也不要要求其中一条必定嵌套在另一条内。带宽敏感性图的横坐标是每次回归选择样本所用的半径，不是单个观测距阈值的距离。

规格曲线可能展示系数、拟合统计量，或多个实验的 t 统计量均值。保留实际统计对象及其标签。t 统计量均值不会仅因名称含有“t”，就自动适用常规的 ±1.96 拒绝阈值。结果行和选择矩阵须按同一设定标识排序；某项选择未被记录，并不能证明该选项已被排除。

## 分布与转变

明确直方图横轴表示的对象：观测结果、个体效应估计、后验抽样值和随机化抽样值是不同输入。个体效应估计的直方图不会展示各个体的标准误，也无法将真实效应分布与估计噪声分离。复用直方图绘图代码并不会消除这些区别。

对于配对二元状态，四种联合类别之和等于完整配对数量。各类百分比使用这个共同分母。条件转变概率，例如 P(after=1 | before=0)，则以初始状态为零的完整配对为分母。若没有配对从零开始，该条件概率未定义，并非零。两组未配对截面的边际分布无法识别四类转变。配对比较假设检验属于需要单独规定的分析，不会自动从来源图继承。

概率校准散点图可将真实或参考概率置于横轴，将预测信念置于纵轴。根据 45 度线解读高估时，应保留这一方向。条件四分位距带概括个体离散程度，并非拟合关系的置信带。零或一处存在大量概率质量时，可能需要明确定义单独的箱，而非普通分位数分箱。

扎堆图比较政策跳跃阈值或折点附近的观测分布与构造的反事实分布。它本身不是断点回归结果拟合、密度连续性检验，也不是行为弹性的估计。必须区分计数、箱内份额和密度单位；反事实构造、排除区间、超额质量归一化及不确定性属于上游分析。不得从图上两条曲线似乎相交的位置推断边际扎堆者或劣势区间边界。

政策等高线坐标轴可能表示概率的相对百分比变化，而非百分点变化。相对增加 10% 将 d 变为 1.1d；增加 0.10 是另一项政策。接受概率变化的等高线与每次就诊支付变化的等高线具有不同结果单位，即使二者共享相同的政策坐标轴。保留实际等高线水平的标签。
